# Руководство «Мой город»

Три роли: **житель**, **диспетчер** организации, **администратор**. Открывать приложение — кнопкой бота в Telegram (в деморежиме — просто в браузере).

## Жителю

### Начать

1. Откройте бота → «Открыть «Мой город»».
2. **Добавить адрес** (кнопка на главной). Адресов может быть несколько — переключаются в шапке, «Мой адрес».
3. В **Настройках** отметьте, о каких услугах получать уведомления для каждого адреса.

### Узнать об отключениях

**Отключения и работы** — текущие, плановые и завершённые события по вашим адресам.
- Фильтры: по направлению (чипы сверху), по услуге (список), поиск по тексту.
- **На карте** — точки событий; у работ, которые идут прямо сейчас, пульсирующее кольцо. Кнопка ◎ — показать, где вы.
- «Срок неизвестен» — организация не указала время окончания; это честный статус, а не ошибка.

### Передать показания

**Показания счётчиков** → **Добавить счётчик** (услуга, название, заводской номер, начальное значение) → **Передать показания**.
- Одно показание на счётчик в месяц; меньше предыдущего — нельзя.
- График расхода и **Экспорт в CSV** (открывается в Excel).
- «Сохранено в сервисе» ≠ принято поставщиком: официальный приём и начисления пока не подключены.

### Заявки и жалобы

- **Мои заявки** — обращение в управляющую/организацию: история, статусы, можно открыть заново после выполнения.
- **Книга жалоб** — городская проблема (яма, свалка…): категория, описание, фото, точка на карте. Тепловая карта показывает, где жалоб больше.

### Транспорт

- **Маршрутки**: номер, «откуда → куда», через сколько минут ближайший рейс (по времени ПМР), интервал, часы работы, цена; линия и остановки на карте.
- **Такси**: выберите «откуда» и «куда» — увидите примерную цену у каждой службы; закрытые сейчас службы — внизу и неактивны. Кнопка с номером сразу звонит.
- В демо маршруты, цены и телефоны **учебные**.

### Внешний вид

**Настройки**: тема (светлая — по умолчанию, тёмная, как в системе), акцентный цвет, крупный текст. Анимации отключаются, если в системе включено «Уменьшить движение».

## Диспетчеру

Роль выдаёт администратор (или `npm run provision`). Видны только своя организация, её услуги и адреса.

- **Панель диспетчера** → очередь заявок с фильтрами → статус по шагам (Новая → В работе → Выполнена).
- **Событие**: создать как **черновик** (никому не уходит) → проверить → **Предпросмотр** покажет, сколько подписчиков получат уведомление → **Опубликовать**.
- Изменение опубликованного события создаёт новую версию и повторное уведомление; если форму успел поменять коллега — придёт предупреждение, а не тихая перезапись.
- **Графики обслуживания** — плановые работы по домам.

## Администратору

- **Организации**: название, услуги, адреса зоны ответственности, отметка «кабинет подключён». Пересекающиеся зоны одной услуги система не даст сохранить.
- Назначение диспетчера: человек сначала один раз входит через бота, затем добавляется в `dispatchers` конфигурации `provision` (`telegramId` + `organizationId`).
- Приём отключений от организаций по API: `POST /api/integrations/outages`, заголовок `x-api-key: INTEGRATION_API_KEY`. Записи попадают в **черновики** и публикуются диспетчером.

## Деморежим

Работает без сервера, данные хранятся в браузере. «Панель диспетчера» переключает учебную роль. **Режим защиты** — четыре шага, показывающие путь от черновика до принятой заявки. Сбросить демо — в Настройках.
